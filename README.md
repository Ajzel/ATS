🚀 ATS Resume Analyzer using Gemini AI

This project is an AI-driven Applicant Tracking System (ATS) Resume Analyzer that helps candidates evaluate how well their resume matches a job description. It simulates how modern ATS and HR professionals screen resumes.

Built using Streamlit, Google Gemini AI, and PDF-to-Image processing, the app provides intelligent feedback and keyword matching insights.

✨ Key Features

✔ Upload resume in PDF format
✔ Paste any Job Description
✔ Get an AI-based professional HR evaluation
✔ View strengths and weaknesses of the resume
✔ Receive an ATS match percentage
✔ Identify missing keywords to improve resume ranking

🧠 How It Works

The uploaded resume PDF is converted into an image

The image and job description are sent to Google Gemini

Gemini analyzes content like an ATS + HR expert

The system returns:

Resume evaluation

Improvement suggestions

Match percentage and missing skills

🛠 Tech Stack

Frontend: Streamlit

AI Model: Google Gemini (gemini-2.5-flash)

PDF Processing: pdf2image + Pillow

Language: Python

Students preparing for placements
